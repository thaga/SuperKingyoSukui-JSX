Super Kingyo Sukui in JSX
======================================

This is a JSX port of X68000 Super Kingyo Sukui.

Notes
======================================

This application uses `requestAnimationFrame()` emulation.
If you want to use native RAF, add `#raf` to the end of the URL.

* [https://thaga.github.com/SuperKingyoSukui-JSX/](https://thaga.github.io/SuperKingyoSukui-JSX/) (emulated RAF)
* [https://thaga.github.io/SuperKingyoSukui-JSX/#raf](https://thaga.github.io/SuperKingyoSukui-JSX/#raf) (native RAF)
